# 첫집 내비 · 디자인 규칙 (내 첫 집 파일)

`my-house` React 프로젝트의 화면 규칙이에요. 2026-11-18 기준이고, PC 화면(가로 1240px 이상)만 다뤄요.
원본 `~/Downloads/index/firsthome.html`의 규칙을 그대로 가져왔고, 바뀐 곳은 처음 화면의 웹 화면 그림(2절), 3초 로딩 화면(6절), 파일 구조(8절)예요.

---

## 1. 컨셉: 내 첫 집 파일

### 01 입력 개편 (2026-11-18)

- 본문과 오른쪽 요약을 **기본 정보 / 나의 예산 / 이사·이동 조건** 세 구역으로 묶어요. 01 전용 스타일은 `src/styles/step1.css`에 있어요.
- **직업·학업 상태**는 네이티브 체크박스로 복수 선택해요. 직장인과 대학(원)생을 함께 골라도 학생 대상 지원에 반영돼요.
- **통근·통학 기준 장소**는 검색 결과의 장소명과 주소·위치 정보를 세로 목록으로 보여줘요. 고른 뒤에는 장소와 [변경]만 남겨요. 허용 이동 시간은 같은 구역에 있어요.
- **입주 시기**는 연도·월 드롭다운과 [아직 미정]으로 골라요. 연도만 고르면 미완료, 미정을 고르면 완료예요. 올해의 지난달은 선택하지 못해요.
- 로딩 화면과 02~04의 레이아웃은 기존 구성을 유지해요.

아래의 기존 01 입력 설명보다 이 개편 규칙을 우선해요.

처음 독립하는 청년이 단계를 지날 때마다 **한 파일에 내용이 쌓이는** 구조예요.

| 장 | 이름 | 쌓이는 것 |
|---|---|---|
| 01 | 내 조건 | 9가지 답 (나이, 소득, 모아둔 돈, 자주 가는 곳 …) |
| 02 | 받을 지원 | 받을 수 있는 금액과 공고문 근거 |
| 03 | 집 고르기 | 후보 집 2~3곳 비교, 확인할 것 |
| 04 | 할 일 | 01~03에서 나온 마감·전입신고·확인할 것 체크리스트 |

원칙 세 가지 (처음 화면에도 그대로 적혀 있어요)

1. **공고문 근거**: 받을 수 있다고 한 지원마다 공고문 원문 문장을 같이 보여줘요.
2. **숫자는 코드가 계산**: 금액, 점수, 시간은 정해진 규칙으로 계산해요. AI는 그 결과를 설명만 해요.
3. **모르면 '확인 필요'**: 모르는 값은 0으로 치지 않아요. 값은 `null`로 두고 화면에 '확인 필요'로 보여요.

## 2. 화면 구성

```
┌ 위 막대 60px (고정) ─ 로고 · '내 첫 집 파일 · 0n 장 이름' · 쉬운 화면 ┐
├──────────┬──────────────────────────────┬──────────┤
│ 목차 200 │ 본문 (나머지, 약 740px)       │ 도구 300 │
│ (고정)   │ 장 머리 → 내용 → 아래 버튼     │ (고정)   │
└──────────┴──────────────────────────────┴──────────┘
  전체 폭 최대 1360px · 최소 1240px · 칸 사이 36px · 양옆 24px
```

- **목차** (`.rail`, 위에서 84px에 고정)
  - 01~04를 세로로 보여줘요. 지금 장은 흰 카드에 초록 번호예요.
  - 끝난 장은 번호 대신 ✓를 보여줘요.
  - 장마다 쌓인 내용을 한 줄(`chSum`)로 보여줘요. 예: "최대 520만 원", "3곳 · 1위 A 성수동", "9개 남음".
- **본문** (`main.col`): 장 머리(`chHead`)로 시작하고, 아래 버튼(`.cta`)으로 끝나요.
- **도구** (`aside.side`, 위에서 84px에 고정): 화면보다 길면 그 안에서 스크롤돼요.

  | 장 | 도구 칸에 나오는 것 |
  |---|---|
  | 01 | 내 조건 진행 + [받을 수 있는 지원 보기] |
  | 02 | 공고 알림 + 내 조건 요약 |
  | 03 | 집을 넣는 중: 넣는 요령 + 내 조건 요약<br>비교 중: 작은 지도 + 확인할 것 |
  | 04 | 파일 요약 + [파일 전체 복사하기] + 내 조건 요약 |
- **쉬운 화면** (`.easy`)
  - 목차와 도구 칸을 없애고 가운데 860px 한 칸만 보여줘요.
  - 위 막대에 4단계 버튼이 나와요. 글자는 더 크게 써요.
- **처음 화면** (`.lp`, 폭 1120~1200px): Toss·당근 서비스 소개 화면처럼 **큰 한 문장 + 버튼 하나**로 시작해요. 위에서 아래로 다음 순서예요.
  1. **위 막대**: 처음엔 투명하고, 스크롤하면 종이색 + 흐림 효과(`.lp-top.sc`). 오른쪽에 쉬운 화면, [시작하기].
  2. **첫 문장**: 가운데 정렬 72px "첫 독립, 받을 돈부터 챙겨요". 둥근 큰 버튼 [내 파일 만들기] 하나, 옆에 글자 링크 '쉬운 화면으로 볼래요'.
  3. **떠 있는 결과 카드 3장**: 받을 지원금, 먼저 볼 집, 할 일. 살짝 기울어져 천천히 떠다니고, 금액은 0부터 올라가요.
  4. **스크롤 이야기**: 왼쪽에 01~04 글이 지나가요. 오른쪽에 고정된 **웹 브라우저 창**(`.bw`, 600×440)이 그 장에 맞게 바뀌어요.
     - 앱은 쓰지 않으니 폰 대신 실제 PC 화면 틀을 줄여서 보여줘요. 이야기 칸은 `글 1fr | 창 600px`, 사이 64px이에요.
     - 창 위 막대(`.bw-bar`, 40px): 점 3개 · 자물쇠 · '**내 첫 집 파일** / 0n 장 이름'. 실제 도메인은 적지 않아요.
     - 창 안(`.bw-body`): 왼쪽 목차 108px(01~04, 지금 장 흰 카드, 끝난 장 ✓) + 본문 + 오른쪽 도구 칸 138px. 실제 화면의 `목차 · 본문 · 도구` 3칸과 같은 순서예요.
     - 01: +500만 버튼이 눌리며 보증금이 2,000만 원까지 쌓여요. 도구 칸은 '내 조건 7/9'.
     - 02: 금액이 520만 원까지 올라가고 근거 줄이 떠요. 도구 칸은 근거 칩.
     - 03: 순위 막대가 차올라요. 도구 칸은 작은 지도 + 범례.
     - 04: 체크가 하나씩 켜져요. 도구 칸은 파일 요약.
     - 장면이 바뀔 때 창 안 화면은 0.45초 동안 14px 올라오며 나타나요. 움직임 줄이기 설정이면 바로 바뀌어요.
  5. **질문이 흐르는 줄**: 공고문에 물어볼 수 있는 예시 질문(`QA`) 두 줄이 서로 반대로 흘러요. 마우스를 올리면 멈춰요.
  6. **숫자 카드 4장**: 지원 판정 10개, 공고문 조각 1,300여 개, 후보 집 3곳까지, 로그인 0번. 보이면 0부터 올라가요.
  7. **원칙 한 문장**과 3가지, **마지막 초록 배너**와 [내 파일 만들기].
  - 카드와 창 그림에 나오는 숫자는 모두 앱 계산 그대로예요. 예시 인물(만 27세 · 월 230만 원 · 무주택)과 예시 집 3곳으로 `judge()`, `scores()`를 돌려요.

### 장 머리 (`chHead(n, 제목, 설명, 오른쪽)`)

```
[01] 내 조건                ← 장 번호 칩 + 장 이름 (13px)
내 상황을 알려 주세요   [예시로 채우기]  ← h1 32px / 오른쪽 버튼 자리
설명 한두 줄 (15.5px, 최대 680px)
```

- 제목에서 강조할 숫자나 말은 `<em>`으로 감싸요. 초록으로 보여요.
- 장 번호는 `CH` 배열 하나에서만 가져와요.

규칙

- 초록은 **누를 수 있거나 고른 것**에만 써요. 장식이나 큰 숫자를 칠하지 않아요.
- 빨강은 '안 맞음'에만 써요. 경고나 마감은 주황 계열(`--caution`)로 써요.
- AI가 만든 문장이나 판정은 보라로만 구분해요. 코드가 계산한 숫자는 보라로 쓰지 않아요.

### 01 입력 부품

항목 성격에 맞춰 입력 방식을 골라요. 고정된 보기 몇 개만 고르게 하지 않아요.

| 항목 | 부품 | 동작 |
|---|---|---|
| 보증금으로 쓸 돈 | **금액 + 더하기 버튼** (`moneyBox1`) | 큰 숫자를 직접 적거나 [+100만] [+500만] [+1,000만] [+5,000만]으로 더해요.<br>[지우기]로 비워요. 1억 이상은 옆에 "1억 2,000만 원"처럼 읽어 줘요. |
| 한 달 수입 | 월급/연봉 전환 + 금액 + 더하기 버튼 + **소득 막대** | 월급은 [+10만] [+50만] [+100만], 연봉은 [+100만] [+500만] [+1,000만]이에요.<br>막대에는 지원 소득 기준선(월 385만 원)이 있어요. 넘으면 막대가 주황으로 바뀌어요. |
| 출생연도 | **−/+ 버튼 + 직접 입력** | 비어 있을 때 누르면 1999년(만 27세)부터 시작해요. 4자리가 되면 저장하고, 범위 밖이면 안내해요.<br>판정이 갈리는 연도만 생일 질문이 떠요. |
| 출퇴근 시간 | **슬라이더** 10분~1시간 30분, 5분 단위 + [상관없어요] | 밀면 문구와 오른쪽 패널이 바로 바뀌어요. 정하기 전에는 회색 손잡이예요. |
| 입주 시기 | **달 고르기** 이번 달 · 다음 달 · 그다음 두 달 · 미정 | 오늘 날짜에서 계산해요. 값은 Step1Rules 형식(`'이번 달'`, `'1월'` …)이에요. |
| 본인 명의 집, 부모님과 같은 주소 | **미리보기 카드** | 고르면 어떻게 되는지 한 줄씩 보여줘요. 예: "이사하며 세대 분리하면 돼요". |
| 지금 상황 | 칩 | 그대로 |
| 자주 가는 곳 | 검색 + 후보 칩 | 그대로 |

- 더하기 단위는 `ADD1` 한 곳에서 바꿔요. 슬라이더 범위는 `T_RANGE1`, 연도 범위는 `step1_rules.js`의 `years`에서 와요.
- 금액을 더하면 숫자가 살짝 커졌다 돌아와요(`bump`). 포커스는 누른 버튼에 남아 있어서 키보드로 계속 더할 수 있어요.

### 움직임

- 처음 화면만 크게 움직이고, 01~04 작업 화면은 버튼 눌림(`scale .93`)과 막대가 차오르는 정도로만 움직여요.
- 나타나기: 아래에서 32px 올라오며 0.8초, 순서대로 0.08~0.54초 늦게. `IntersectionObserver`로 화면에 들어올 때 한 번만 해요.
- 숫자 올라가기: 0.4~1.5초, 끝으로 갈수록 느려져요(`1 - (1-p)^3`).
- `prefers-reduced-motion`이면 떠다니기, 흐르는 줄, 숫자 올라가기를 모두 끄고 결과만 보여줘요.
- 스크립트가 없어도 내용이 보이도록, 숨김은 `.lp.js` 안에서만 걸어요.

## 6. 장별 내용 순서

- **01 내 조건**: 장 머리(+ 예시로 채우기) → 9개 항목 카드. 항목마다 입력 부품은 5절 '01 입력 부품'을 따라요.
  - 빠진 항목으로 가면 주황 바탕(`.f1.hl`)으로 표시해요.
- **01 → 02 로딩 화면** (`Loading.jsx`, `.ld`): 01에서 [받을 수 있는 지원 보기]나 목차의 02를 누르면 3초(`LOADING_MS`) 동안 보여줘요. 쉬운 화면도 같아요.
  - 위 막대·목차·도구 칸 없이 종이색 바탕 가운데 흰 카드 하나(폭 600px, 모서리 24px)만 보여요. 왼쪽 위에 로고만 있어요.
  - 카드 순서: 집 아이콘(지붕 → 벽 → 문 순서로 그려져요) → '02 받을 지원' → 제목 30px "내 조건으로 받을 수 있는 지원을 찾고 있어요" → 진행 막대 8px + % → 판정 4줄 → 안내 한 줄.
  - 판정 4줄은 실제 판정 순서예요: 나이 조건 → 소득 기준 → 무주택·세대 → 공고문 근거. 끝난 줄은 초록 ✓와 내 값(예: "만 27세", "월 230만 원 · 중위 90%"), 하고 있는 줄은 도는 원이에요.
  - 줄은 3초를 4.3칸으로 나눠 차례로 끝나요. 마지막 줄이 3초 전에 끝나서 100%와 ✓ 4개를 잠깐 보고 넘어가요.
  - 시간은 50ms마다 실제 지난 시간으로 다시 재요. 탭이 뒤에 있어도 3초에 맞게 넘어가요.
  - 진행 막대는 `role="progressbar"`, 지금 단계는 `role="status"`로 화면 읽기 프로그램에 알려요.
  - 움직임 줄이기 설정이면 그리기·돌기·튀어나오기를 끄고 ✓와 숫자만 바뀌어요.
  - 실제 계산은 바로 끝나요. 로딩은 "내 조건을 공고문과 맞춰 본다"는 걸 보여주려는 화면이에요. 그래서 문구에 "숫자는 코드가 정해진 규칙으로 계산해요"를 같이 적어요.
- **02 받을 지원**: 아래 순서로 보여줘요.
  1. 장 머리 + 금액 막대
  2. 내년에 신청할 지원 (합계, 중복 안내, 세대 분리 안내)
  3. 지금 신청할 수 있어요 (카드 + 04 할 일 안내)
  4. 공고문에 물어보기 (AI)
  5. 조건이 바뀌면?
  6. 지금은 받기 어려운 지원
- **03 집 고르기**
  - 집 넣기: 장 머리 → 지도 → 집 칸 3개 → 주소 검색 / 계약 조건.
  - 비교: 장 머리(+ 집 바꾸기) → 차이 요약 + 비교표 → 순서 정리 → 이 비교에 물어보기 → [할 일 정리하기].
  - 비교표 머리는 위 막대 아래(60px)에 붙어요.
  - 관리비를 모르는 집은 순위에서 빼고 '확인 필요'로 보여요.
- **04 할 일**
  - 장 머리 → 계약 전에 / 이사하면서 / 지금 신청할 수 있어요 / 내년에 신청할 지원 → 신청 일정 달력 → [파일 전체 복사하기].
  - 할 일은 새로 계산하지 않아요. 02의 판정(`judge`, `moreJ`)과 03의 확인할 것(`cmpChecks`)을 그대로 모아요.
  - 체크하면 목차와 파일 요약 숫자가 바로 바뀌어요.
  - 03의 '확인할 것' 체크와 같은 값(`S.chk`)을 써요.

## 8. 파일 구조 메모

React(Vite) 프로젝트예요. 원본 `firsthome.html`의 함수가 어디로 갔는지 적어요. 실행 방법과 폴더 전체는 `README.md`에 있어요.

- **계산·판정·데이터는 `src/lib/core.js`** 한 곳이에요. 원본 함수를 그대로 옮기고 `export`만 붙였어요.
  - 판정: `me`, `judge`, `moreJ`, `whatifs` · 비교: `scores`, `reasons`, `cmpChecks` · 할 일: `todoFlat`, `chSum`
  - 01 입력: `ADD1`, `add1`, `yearStep1`, `T_RANGE1`, `whenOpts1`, `pick1`, `CARD1`
  - 문구 안 `{NM}` 같은 자리는 `fill()`로 채우고, HTML이 들어 있는 문구는 `ui.jsx`의 `Html`로 그려요.
- **화면을 그리던 함수는 컴포넌트**가 됐어요.

  | 원본 | React |
  |---|---|
  | `header`, `footer`, `rail`, `aside` 안 패널들 | `components/Shell.jsx` |
  | `chHead(n, 제목, 설명, 오른쪽)` | `components/ui.jsx`의 `<ChHead n h1 lead right/>` |
  | 01 화면 (`moneyBox1`, `gauge1`, `yearIn1`, `time1` …) | `pages/Step1.jsx` |
  | 02 화면 | `pages/Step2.jsx` |
  | 03 집 넣기 · 비교 · 동네 자세히 | `pages/Step3.jsx` |
  | `todoPage`, 달력 | `pages/Step4.jsx`, `components/Calendar.jsx` |
  | `homePage`, `homeInit`, `lpPlay`, `lpCount` | `pages/Home.jsx` (`WebShot`, `Count`, `countTo`) |
  | (새로) 3초 로딩 | `pages/Loading.jsx` |

- **상태는 `src/store.js`의 `S` 하나**예요. `set({...})`으로 바꾸면 전체를 다시 그려요. `go(2)`를 01에서 부르면 바로 02로 가지 않고 `S.loading = true`가 돼요.
- **CSS**
  - `styles/app.css`: 원본 `<style>` 그대로예요 (폰 그림 부분만 뺐어요). 디자인 값은 맨 끝 `내 첫 집 파일 · 새 디자인` 블록(약 688줄)의 `:root`에 모여 있어요. 색을 바꿀 때는 그곳을 먼저 고쳐요.
  - `styles/web-mockup.css`: 처음 화면의 브라우저 창 그림
  - `styles/loading.css`: 로딩 화면
- 원본 파일(`~/Downloads/index/`)은 건드리지 않았어요.
- 아직 확인하지 않은 것
  - 실제 카카오 지도·ODsay 교통 (키가 있을 때)
  - AI 서버가 켜져 있을 때의 답변 카드 (`/api/ask`, `/api/compare`)
  - 가로 1240px 미만 화면
